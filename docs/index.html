O que já vem pronto

Nada disso precisa ser configurado depois de gerar o projeto.

banco de dados

gbit-db-dados já conectado ao backend

O motor de banco de dados roda dentro do próprio GBIT Database — não é um serviço separado que você precisa apontar host, porta e senha. Assim que o servidor sobe na porta 4200, o banco já está respondendo.

GET / → { "engine": "GBIT Database", "status": "online" }
portal

IA de código offline

Descreve uma tabela em texto e o Portal gera schema, rotas de API e tipos TypeScript prontos para copiar. Sem chave de API.

orquestração

Pronto para o gbit-container

Escolha o stack gbit-db e suba App, Database e Portal juntos, com dashboard e sem Docker.

Como funciona

Do zero até as três URLs abertas no navegador.

01

Gerar o projeto

Cria a estrutura completa na pasta atual.

npx gbit-db meu-projeto
02

Instalar as dependências

Na raiz do projeto e dentro de gbit-database/.

npm install
03

Escolher o stack no gbit-container

Gera a configuração dos três serviços automaticamente.

gbit-container stack gbit-db
04

Subir tudo

App, Database e Portal sobem juntos.

gbit-container up
05

Abrir o dashboard e copiar a URL

Sem rodar nada manualmente a partir daqui.

gbit-container dashboard

Estrutura do projeto gerado

Tudo organizado desde o primeiro comando.

meu-projeto/
├── src/                    # páginas, rotas de API, portal
├── gbit-database/          # servidor do banco (roda em :4200)
│   └── server.js
├── scripts/                # portal.mjs
├── gbit.yml                # gerado por `gbit-container stack gbit-db`
├── next.config.mjs
├── tsconfig.json
└── package.json
